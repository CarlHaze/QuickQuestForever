# QuickQuestForever

A lightweight addon for WoW: Forever Beta that speeds up questing — auto-accepts quest offers and auto-completes turn-ins.
## Features

- Auto-accepts quests from NPCs (`QUEST_DETAIL`)
- Auto-completes quests once turn-in requirements are met (`QUEST_PROGRESS` / `QUEST_COMPLETE`)
- Auto-confirms rewards only when there's a single choice (or none) — multi-choice rewards are left for you to pick manually
- Auto-selects a quest on NPCs offering only one active/available quest (both the classic greeting window and the modern gossip frame)
- Hold **Shift** at any moment to bypass automation for that interaction
- `/qq` to toggle the addon on/off

## Installation

1. Download the latest release (or clone this repo).
2. Copy the `QuickQuestForver` folder into `World of Warcraft/_classic_beta_/Interface/AddOns/`.
3. Restart the game or `/reload`.

## Compatibility

Built and tested against WoW: Forever Beta (client 1.60.1).
